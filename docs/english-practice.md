# 小安英语练习固件

> 固件实现与服务端联调分别在各自 PR 审阅。设备端由 [固件 #22](https://github.com/yuyuyulin/AgentSphere-esp32/issues/22) 交付。网页、提示词和场景服务由 [AgentSphere #61](https://github.com/yuyuyulin/AgentSphere/issues/61) 交付并维护联调契约。

## 首版操作

1. 孩子在小安主页左滑，点「英语练习」。页面显示正在进入，服务端确认后小安先问一句。
2. 听完后短按 `BOOT` 开始回答，再按一次结束收音。等待和播放时沿用日常语音的按键打断。
3. 「重听」播放本局最近一次听完的回复。「退出」立即停止播报并回首页。再次进入开新一局。
4. 家长在 AgentSphere 网页修改一份自定义提示词，下一局生效。设备上共用同一个入口和练习界面。

练习页显示倾听、思考和播放状态，以及重听和退出。存在播报字幕时使用现有下行字幕显示策略。缺少字幕时保留状态操作。有屏设备在首页始终可左滑打开「英语练习」入口并展示 `ABC / 开始练习` 图标；点击图标时再按实时状态处理——离线/连接中提示「联网后再试」并唤醒重连，初始握手未开启练习能力时触发一次重新握手向服务端实时确认（若服务端已开启则自动进入，仍未开启时提示「未开启，请先在网页端开启」）。闭麦状态继续应用于练习收音。

## 改动与验证顺序

### 1. 接入独立场景

- 修改 `main/protocol/voice_client.h` 和 `main/protocol/voice_client.cc`。有屏设备在 v1 握手声明 `features: ["english_practice", "captions_v1"]`，初始场景为 `default`。按 `hello_ack.scenes` 判断练习能力。
- 每次开局由设备生成 `request_id` 和开场 `turn_id`。收到匹配的 `scene.ack` 后保存服务端 `practice_id`，再按同一局、同一轮接受开场 `tts.start`。开场直接播放，麦克风等待孩子按键才开启。
- 练习轮沿用 Opus 帧和回执。客户端按控制帧校验场景、`practice_id` 和 `turn_id`。练习录音收到同一局、同一轮的 `listen.ack` 后才上行 Opus 音频帧。收音和播放共用现有单轮状态。重听通过 `scene.repeat` 携带新的 `turn_id`，服务端重放最近完整语音。
- 退出时先本地停止播放和收音、清队列，再发送 `scene.exit`。服务端确认后继续日常语音。退出超时则重连并回到日常。设备丢弃旧练习的迟到回复。断线、解绑或开局失败退回日常。
- 用替身 WSS 和主机回归覆盖无场景能力的旧服务端、进入成功与超时、重复或迟到确认、切换后拒收旧练习播放头、断线复位与重听。真人听测等两端联调。

### 2. 接入圆屏

- `main/app/application.cc` 负责转发场景动作、显示状态和应用现有闭麦、息屏规则。对应事件在 `main/app/events.h` 定义，`main/ui/display.h` 仅约定通用显示边界。
- `main/ui/round_amoled/` 负责识别首页左滑、显示入口和练习页，复用已有手势过滤及 LVGL 锁。验证左滑与首页点击、下滑快捷面板可以独立操作。
- 主机回归覆盖手势和场景切换，分别构建 ESP32-S3 圆屏版和无屏版。板级接口、音频格式和开关机规则沿用现有实现。

### 3. 两端验收

| 验收项 | 微雪 1.75C 观察结果 |
| --- | --- |
| 默认开局 | 左滑点入口，听到小安用英语先问一句。短按 BOOT 回答，完成多轮。 |
| 重听 | 按重听听到相同的上一句，练习继续。 |
| 配置生效 | 网页保存两个不同话题之一，下一次进入时听到相关问题，操作路径一致。 |
| 独立会话 | 在练习时说出一个测试词，退出后用日常对话确认上下文独立。 |
| 退出与重连 | 在播报或等待时退出，音频立即停止。之后回来只播新练习。断线恢复后回到日常。 |
| 兼容和闭麦 | 连接旧服务端时日常问答可用。闭麦时练习页禁止发起新收音。 |

构建成功、替身协议通过、设备播放回执和用户听测分别记录。

## 当前验证记录

- 六项主机回归通过。语音消息替身用真实固件 `VoiceClient` 与 cJSON，覆盖旧服务端（点击查服务端并提示未开启）、后台动态开启后点击自动进入、无屏协商、开场、重听、闭麦、多轮收音、关联校验、退出停播、过期语音、拒绝进入、断线和超时。
- ESP-IDF v6.1（`esp32s3`）圆屏固件 `0x24ed40`，应用分区余量 42%。无屏版 `0x136e50`，余量 70%。
- 微雪 1.75C 真机实测确认：首页左滑可稳定打开英语练习入口，完整渲染 `ABC / 开始练习` 图标卡片与底部「返回」按钮（关闭 LVGL 默认按钮阴影与切态整屏重绘后无花屏），点击图标实时核验服务端并在平台总开关未开启时正确提示「未开启，请先在网页端开启」。两端完整英语多轮对话与听测待服务端开启平台总开关后继续验收。
