# 小安精简版固件设计

2026-11-25 · 关联 Issue #14。适用于微雪 1.75C。保留现有小安主页、手机配网和网页认领，从自动息屏开始完善日常使用。

## 界面

日常只有小安主页和一个下滑面板。从主页上缘下滑打开面板，上滑或点返回回到主页。面板提供音量、亮度和闭麦三个控件，用小图标显示电量与联网状态。三个偏好修改后立即生效，重启后恢复。闭麦时，短按 `BOOT` 仍可点亮屏幕，收音保持关闭。

首次使用和添加新 Wi-Fi 沿用现有手机配网，长按 `BOOT` 可以手动进入配网。已保存网络由固件自动选择，圆屏继续使用现有配网和配对页面。

## 交付顺序和验收

### 1. 插电自动息屏和按键唤亮

- 插电空闲到点后全黑，设备保持开机和联网。先用固定 **60 秒**试用，根据真机体验调整。
- 用户操作重置空闲计时。正在收音、等待回复、播报、配网或查看配对码时暂停计时，回到空闲后重新计算。息屏后继续维持当前网络连接和语音连接。
- 息屏时短按 `PWR` 只点亮屏幕。短按 `BOOT` 点亮屏幕，语音可用且麦克风打开时直接进入对话。长按 `PWR` 关机，长按 `BOOT` 进入配网。

**真机验收**观察插电闲置后屏幕全黑，多次用两个按键分别唤亮。在息屏前开始对话，确认录音、等待和播报中屏幕保持可见，对话结束后重新计时。分别进入配网和配对页面，确认空闲计时在流程中暂停。

### 2. 下滑快捷面板

- 只提供音量、亮度、闭麦、电量和联网状态。息屏时长在本版使用固件默认值。
- 闭麦后停止当前收音并禁止再次开始收音。后续新增唤醒词或自动追问时，同样遵守闭麦状态。
- 面板手势与滑杆调整各自生效，关闭面板后回小安主页。

**真机验收**从主页连续打开和关闭面板，拖动滑杆时验证没有误关闭。调整音量和亮度、开启闭麦后重启，核对三个偏好恢复。验证闭麦时短按 `BOOT` 不收音，解除闭麦后可以发起对话。

### 3. 验证自动回连和电池待机

- 开机或断线后扫描已保存 Wi-Fi。优先尝试最近成功且当前可见的网络，失败再尝试其他可见的已保存网络。全部不可用时保留离线主页并后台重试。先验证现有逻辑，按实测补齐差距。
- 测量电池供电时亮屏和息屏后的功耗，检查按键唤醒是否可靠，再决定独立低功耗模式和自动关机时长。屏幕全黑、整机功耗和唤醒可靠性分别记录。

**真机验收**提前保存两个网络，分别只让其中一个可用，验证开机和断线后自动连上可用网络。关闭两个网络后验证离线可用，恢复任一个后自动回连。切换网络后验证原有绑定仍然有效。记录电池模式下亮屏、息屏和多次唤醒的结果。
