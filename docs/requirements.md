# AgentSphere ESP32 产品功能需求文档

更新于 2026-11-25。本文聚焦 **ESP32 设备端** 的 C 端产品需求与交互规范（不涉及服务端具体实现），作为固件开发与后续端云协议对齐的基线。

## 1. 产品定位与硬件基线

- **产品定位**：面向 C 端用户的**手持 / 挂件 / 随身 AI 伴侣通用底座**。主界面提供情感化陪伴与日常语音对话，通过极简菜单承载可选场景（首个场景为轻量级英语口语练习），后续可通过 AgentSphere 配置不同助手人设与场景。
- **首台验证设备**：微雪 `ESP32-S3-Touch-AMOLED-1.75C`（466×466 圆形 AMOLED 触控屏、双麦 + ES7210/ES8311 硬件回声消除、`PWR`/`BOOT` 实体键、AXP2101 电源管理、QMI8658 六轴 IMU、PCF85063 RTC、16MB Flash + 8MB PSRAM + TF 卡槽）。
- **跨设备扩展边界**：配网、设备状态机、认领流程与实体按键逻辑需保持**板级解耦**，确保未来能够平滑适配不同尺寸屏幕，甚至无屏幕的 ESP32 语音设备。
- **设备角色与唤醒词**：角色昵称定为 **「小安」**，主唤醒词定为 **「小安同学」**（配网热点保持 `AgentSphere-XXXX`）；首版采用薄荷绿单弯耳、奶白脸与小黄领巾，后续在 V1.5+ 阶段扩充角色素材和皮肤。

首版日常交互范围和实施顺序见[精简版固件设计](minimal-firmware-plan.md)。以下章节同时覆盖后续能力。电池低功耗和自动关机策略待首版真机测量后确认。

## 2. 开箱、配网与认领（有屏 / 无屏通用）

### 2.1 本地自包含配网（SoftAP + `192.168.4.1`）

配网完全由 ESP32 本地承载，不依赖外部 App、小程序或服务端网页：

- **进入配网的触发规则**：
  - **首次开机（无已保存 Wi-Fi）**：直接自动进入配网模式。
  - **日常开机（已有保存 Wi-Fi）**：自动扫描已保存网络，优先尝试最近成功且当前可见的网络，再尝试其他可见的已保存网络（支持记忆 3~5 个常用 Wi-Fi，覆盖家庭 / 公司 / 手机热点）。连不上时进入**离线模式**并后台重试。需要添加新网络时，提示长按 `BOOT` 进入手机配网。
  - **手动强制配网**：支持开机按住 `BOOT` 键、或在待机时长按 `BOOT` 键。
- **配网流程**：
  - 设备开启热点 `AgentSphere-XXXX`。手机连接后优先触发强制门户（Captive Portal）自动弹窗，同时支持浏览器访问固定地址 `http://192.168.4.1`。
  - 内置配网页提供：2.4GHz 周边 Wi-Fi 扫描列表、密码输入、已保存 Wi-Fi 管理、5GHz 频段不支持提醒、固件版本与设备 ID 查看。
  - **有屏增强**：1.75C 圆屏同步展示热点名、`192.168.4.1` 及热点 Wi-Fi 二维码，方便快速连接；无屏设备直接沿用同一套热点配网。

### 2.2 联网认领（纯配对码方案）

- 设备首次联网（或未绑定状态）后，向 AgentSphere 申请**短期 6 位数字配对码**。
- **1.75C 圆屏**：仅清晰展示 6 位配对码与简短引导（如“请在 AgentSphere Web 输入配对码绑定”），过期后提供一键刷新。不强推扫码跳转登录页，避免手机扫码落入未登录 WebView 造成流程割裂。
- **无屏设备兼容**：状态机与界面解耦，未来无屏设备可将“显示配对码”替换为“本地语音播报 6 位配对码”。
- **绑定安全与验收边界**：覆盖过期码刷新、两人同时认领同一码、已认领设备防抢占、重启保留绑定、解绑后旧凭据立即失效。

## 3. 设备状态机与日常语音体验

### 3.1 设备运行状态机

设备在任意时刻处于单一明确的主状态，各状态流转与行为边界定义如下：

| 状态 | 进入条件 | 设备行为 | 退出条件 |
| --- | --- | --- | --- |
| **启动自检 (`Starting`)** | 通电或按 `PWR` 开机 | 初始化屏幕、音频、传感器与电源管理，读取本地 Wi-Fi 与绑定凭据 | 无已存 Wi-Fi → `配网中`；有已存 Wi-Fi → 尝试联网 |
| **配网中 (`WifiConfiguring`)** | 首次开机无 Wi-Fi、连网失败选择配网、开机按住 `BOOT` 或菜单触发 | 开启 `AgentSphere-XXXX` 热点与本地配网服务，屏幕展示热点与配网引导 | 提交有效 Wi-Fi 并连网成功 → 联网检查；用户选择跳过 → `离线态` |
| **待激活认领 (`Activating`)** | 联网成功但未绑定（或旧凭据已失效） | 向 AgentSphere 申请 6 位短期配对码并展示（无屏设备语音播报），轮询认领状态 | Web 认领成功下发凭据 → `待机`；配对码过期支持手动刷新 |
| **OTA 升级中 (`Upgrading`)** | 联网检查到必须/已确认的新版固件，且电量满足保护阈值 | 显示升级进度、屏蔽普通对话交互，下载并校验写入另一 OTA 分区 | 写入成功自动重启生效；失败或校验不通过保留旧分区回滚至 `待机` |
| **待机 (`Idle`)** | 联网且已绑定，无进行中对话 | 展示主屏陪伴形象；插电态或活跃期开启端侧唤醒词监听，等待按键/触屏/语音触发 | 唤醒命中 / `BOOT` / 触屏 → `倾听`；断网 → `离线态`；电池闲置超时 → `低功耗休眠` |
| **倾听 (`Listening`)** | 唤醒词命中、`BOOT` 键短按、触屏说话，或播报结束自动进入连续追问窗口 | 给出短提示音与“正在录音”边缘光效，采集双麦音频并上传服务端，运行端侧 VAD 检测静音 | VAD 判定说话结束 → `思考/等待`；沉默超时无语音 → `待机`；按 `BOOT`/触屏/倒扣 → 取消回 `待机` |
| **思考/等待 (`Thinking`)** | 本轮音频发送完成，等待服务端首包回复 | 展示思考动画与轻过渡音效，锁定本轮请求 ID 防止重复提交 | 收到服务端音频流首包 → `播报`；超时/错误 → 提示后回 `待机`；按 `BOOT`/触屏/倒扣 → 取消回 `待机` |
| **播报 (`Speaking`)** | 收到服务端返回的语音回复流 | 边接收边解码播报，主屏同步说话律动动画 | 播报自然结束 → 自动进入短暂 `倾听` 窗口等待追问（若已退出场景则直接回 `待机`）；按 `BOOT`/触屏/倒扣 → 立即停止并回 `待机` |
| **离线态 (`Offline`)** | 无法连接已知 Wi-Fi 或运行中网络断开 | 顶部显示离线标识，保留时钟、触摸与 IMU 本地互动；后台按间隔自动尝试重连 | 网络恢复自动回到 `待机`；用户手动触发配网 → `配网中` |
| **低功耗休眠 (`Sleeping`)** | 电池模式下待机超时息屏 | 关闭屏幕与持续音频监听以降低功耗 | 拿起设备（IMU）/ 按 `PWR` → 亮屏回 `待机`；按 `BOOT` → 亮屏直达 `倾听`；长时间无操作 → 自动关机 |

### 3.2 对话交互与容错细则

- **触发对话方式**：
  - **免手语音唤醒**：联网待机且开启唤醒时，端侧本地检测唤醒词，命中后先给出视觉 + 短提示音反馈，再进入 `倾听` 态上传本轮音频。
  - **按键直达**：任意待机或息屏状态下，短按 `BOOT` 键直接进入 `倾听` 态（免唤醒词）。
  - **触屏触发**：主屏轻触说话入口开始本轮录音。
- **多轮追问与打断**：
  - 单轮播报结束后，自动切入短暂的 `倾听` 追问窗口（约 8~10 秒，实测可调），用户直接开口即可继续追问，由端侧 VAD 自动判定说话起止；窗口期内无语音输入则自动退回 `待机`。
  - **一期打断方式**：在 `倾听`、`思考/等待` 或 `播报` 任意阶段，短按 `BOOT` 键、轻触屏幕或倒扣屏幕均可立即打断/取消本轮并回到 `待机`；底层音频管线按 1.75C 硬件 AEC（ES7210 + ES8311）预留能力，后续平滑升级全双工语音打断。
- **端侧零延迟反馈与隐私透明**：
  - 本地内置轻量提示音（唤醒反馈、思考过渡、异常/断网提示），掩盖云端处理延迟。
  - 圆屏边缘状态光效明确区分「本地待机」与「正在上传语音」，控制中心提供**一键闭麦（静音）**，闭麦后暂停端侧唤醒与收音。
- **弱网与异常容错**：
  - 断网、服务超时或识别为空时给出可读提示并支持重试；断线恢复后自动重连；重复触发不乱序播报。
  - 每轮请求携带轮次/会话标识，已取消、超时或已退出场景的云端延迟回复必须在端侧丢弃，不得迟到播出。

## 4. 供电、休眠与实体硬件交互（1.75C 规范）

### 4.1 供电与功耗策略（基于 AXP2101 + RTC）

| 供电状态 | 屏幕与待机表现 | 唤醒方式 | 超时与保护策略 |
| --- | --- | --- | --- |
| **插 USB 供电（桌面态）** | 首版空闲到点全黑，试用默认值 60 秒 | `PWR` 亮屏、`BOOT` 亮屏并进入对话；免手语音唤醒另行接入 | **不自动关机**，保持在线随时可唤 |
| **电池供电（随身态）** | 亮屏活跃期保持连网与对话就绪 | 拿起亮屏（IMU）或按 `PWR`/`BOOT` 唤醒；活跃期支持语音或按键对话 | 1) 无操作定时自动息屏进低功耗待机<br>2) 长时间无操作自动关机防耗电<br>3) 低电量触发“困倦/求充电”表情提示，触及阈值安全关机 |

> 息屏与自动关机具体秒数（如 30~60s 息屏、10~15min 自动关机）结合真机功耗实测后定值，后续可开放设置。

### 4.2 实体按键规范（职责单一，兼容无屏设备）

- **`PWR` 键（电源与屏幕专属）**：
  - 关机态长按：开机；
  - 开机态短按：息屏 / 亮屏切换；
  - 开机态长按（约 3 秒）：关机。
- **`BOOT` 键（对话与配网专属）**：
  - 亮屏待机态短按：直接进入对话模式（免唤醒词）；
  - 息屏/轻休眠态短按：**一键亮屏并直接进入对话**（避免先按 `PWR` 再按 `BOOT` 的二次操作）；
  - 对话收音 / 等待 / 播报态短按：立即取消或打断本轮对话，回到待机；
  - 开机按住（或待机长按 5 秒，带提示防误触）：强制进入配网模式。

> 注：需在 1.75C 实机外壳上验证 `BOOT` 键盲按手感；触屏点击作为日常高频兜底入口。

### 4.3 传感器情感化互动（QMI8658 六轴 IMU）

- **拿起亮屏**：随身电池态下拿起设备自动唤醒屏幕、角色苏醒。
- **摇一摇**：触发眩晕 / 撒娇微动画与轻音效（离线可用）。
- **倒扣屏幕**：屏幕朝下放置时立即停止播报并进入静音 / 息屏。

## 5. 1.75C 圆屏 UI 骨架与视觉分期

- **全中文界面规范**：面向 C 端用户的所有屏幕可见文案（状态提示、配网浮层、配对码浮层、按键/手势反馈、控制中心与升级提示）均**统一使用简体中文**，采用开源中文字体（思源黑体 `SourceHanSansSC` 子集字库，通过 `tools/gen_zh_font.py` 生成并校验字形全覆盖）；6 位纯数字配对码使用大号无衬线数字字体提升远距可读性。
- **后端地址固化**：C 端配网页面（`192.168.4.1`）不向用户暴露后端服务器地址输入框，服务器地址通过编译期配置固化到固件中（开源仓库默认使用占位域名 `https://api.agentsphere.example`，本地生产构建通过 `.gitignore` 忽略的 `sdkconfig.local` 注入）。
- 精简版采用 **1 个主屏 + 1 个下滑面板**，场景菜单随后续场景开放。

1. **主屏（Home · 情感陪伴与对话）**
   - **第一期视觉**：纯黑 AMOLED 主屏使用小安的半身近景。启动与触摸等开心反馈短时显示全身招手姿态，待机和离线保留眨眼，倾听、思考与播报对应独立表情。配网和认领页面优先，息屏停止角色动画。角色姿态、开麦提示与电量状态各自跟随设备事件。
   - **后续联动**：跟随实际播放音量的嘴型、英语练习庆祝及低电/充电状态联动分别随相应功能实现和验收。
   - **离线可玩**：无网时依然保留时间显示、触摸反馈与摇晃互动，不变成“黑砖”。
   - **二期扩展架构**：将「设备状态机事件」与「皮肤/角色渲染引擎」彻底解耦，预留 16MB Flash 独立资源分区及 TF 卡槽扩展位，后续逐步丰富完整玩偶形象、多套主题皮肤与音效包。
2. **下滑 → 快捷控制中心**
   - 音量调节、亮度调节、一键闭麦、电量与 Wi-Fi 状态。
   - 音量、亮度和闭麦立即生效并跨重启保存。Wi-Fi 自动回连，新增网络经 `BOOT` 长按进入原有配网流程。
3. **后续扩展 · 场景菜单**
   - 通用场景卡片容器，场景功能上线时包含两个入口：
     - **日常对话**（默认）
     - **英语口语练习（第一期极简版）**：点击进入后切换至独立的英语练习上下文，圆屏以明确主题色/角标区分当前模式；首期以**纯语音口语互动 + 重听/简单提示 + 随时退出**为主，退出即结束本局并返回主屏。未来可扩展更多场景卡片（故事、番茄钟、不同角色模式等）。

## 6. C 端量产级基础能力

- **后续扩展 · OTA 空中升级**：联网检查固件版本，支持升级进度提示、低电量禁止升级、ESP-IDF 双分区机制（启动失败自动回滚旧版，防止变砖）。
- **AMOLED 防烧屏**：首版通过空闲超时息屏实现。
- **固件分层解耦**：
  `板级 BSP 驱动层` ↔ `音频与唤醒管线` ↔ `设备状态机 & AgentSphere 协议层` ↔ `UI 场景与皮肤资源层`。
- **异常自愈**：硬件看门狗防死机、内存/PSRAM 水位保护、所有异常提示翻译为自然语言/直观图标（不直接暴露技术错误码）。

## 9. 待后续实测与选型确认项

1. **真机实测阈值**：电池模式默认息屏时长、自动关机时长、低电关机阈值，以及真实家庭环境下的唤醒灵敏度与响应延迟基准。
2. **协议与音频选型**：ESP32 与 AgentSphere 之间的传输协议（WebSocket / MQTT + UDP 等）、音频编码格式（如 Opus）、以及端侧唤醒模型与 VAD 参数。
3. **设备转让与恢复出厂规则**：恢复出厂是否同步通知服务端解绑，或由新用户在 Web 端触发解绑流程。
4. **首版英语练习细节**：确认是否需要限制电池模式或独立权限，以及是否随 V1.0 同步发布。
