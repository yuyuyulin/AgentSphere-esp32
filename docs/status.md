## 小安精简版日常固件（#16）

依据 [精简版设计 PR #15](https://github.com/yuyuyulin/AgentSphere-esp32/pull/15) 实施。插电及电池供电时，闲置约 60 秒后关闭显示，设备继续运行并维持联网，对话及配网认领页面暂停空闲计时。圆屏下滑面板提供音量、亮度、闭麦、电量和联网状态，三个偏好写入 NVS。自动联网按最近成功顺序尝试可见的已保存网络，单一候选失败后继续尝试下一候选。

ESP-IDF v6.1（`esp32s3`）构建通过。圆屏固件 `0x24b6b0`，应用分区余量 43%。无屏固件 `0x135130`，余量 70%，链接映射中无小安素材。四项主机回归覆盖息屏计时、面板交互规则与偏好、闭麦与 Wi-Fi 候选顺序，以及原有角色姿态。

微雪 1.75C 使用 `app-flash` 写入应用并校验成功。串口确认保存的 Wi-Fi 和语音连接恢复。开机后约 68.7 秒触发自动息屏并执行 AMOLED 亮度关闭操作，息屏后连续两次遥测仍为插电、在线待机。观察期内无复位或看门狗故障。

待真机操作验收：偏好跨重启保存、电池待机功耗。两个已保存网络间的自动切换暂缓实测。
