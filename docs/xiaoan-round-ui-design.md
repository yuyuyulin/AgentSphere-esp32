# 小安圆屏界面优化方案（草稿）

关联 [固件 #11](https://github.com/yuyuyulin/AgentSphere-esp32/issues/11)、[形象 #8](https://github.com/yuyuyulin/AgentSphere-esp32/issues/8) 和 [AgentSphere 字幕 #57](https://github.com/yuyuyulin/AgentSphere/issues/57)。此稿供评审和手动派发。现有交互基础见 [需求](requirements.md) 与 [交付状态](status.md)。

圆屏目前会更新 Wi-Fi 名称与 IP、详细电量、姿态和时间、最近事件等技术信息。日常界面以小安为主，操作提示只在对应场景出现。详细诊断留在串口。以下布局和文案为拟议方案。

## 本次实现

圆屏日常布局以小安为中心，拿掉技术信息标签和触摸坐标反馈点。聆听时顶部显示麦克风指示，语音接收、思考和播报使用下方短提示。配网和配对继续使用专用页面，断网时提示长按 BOOT 配网。电池供电且已知电量为 0%–15% 时显示充电提示，接入供电或充电时收起。这个阈值只用于界面提示。

下方文字区为后续字幕留出位置。真实字幕消费随语音固件和端云合同联调。

## 圆屏状态

| 场景 | 圆屏内容 |
| --- | --- |
| 已绑定且联网待机 | 小安居中，保留眨眼和轻触招手。常驻画面只显示形象。 |
| 聆听和思考 | 用小安状态表情和短提示区分聆听、思考。收到本轮转写后，在下方字幕区显示。 |
| 播报 | 保留小安形象，下方显示当前回复字幕。优先保证可读的大字，建议最多两行，超出可见区域用省略号。字幕随本轮实际播放出现。 |
| 离线或服务不可用 | 小安配一条简短的行动提示，如「网络断开」或「暂时无法对话」。需要配网时才显示已有操作入口。 |
| 配网和设备认领 | 优先展示完成当前步骤所需的热点、二维码或配对码，以及既有刷新操作、倒计时和可用反馈。 |
| 低电量及息屏 | 低电时短提示，已有电源键和恢复行为继续使用。亮屏后依据当前状态恢复，成对显示字幕和播报。 |

字幕下沿留出圆屏安全边距，按字形宽度换行。首轮覆盖中英文、数字、常用标点及缺字回退，使用实际转写和回答样本验收字库。正常画面避免 Wi-Fi 名称/IP、电压、姿态、传感器数值和事件名；它们各自留在任务页面或串口的既有用途内。待机图案、触摸、按键、配网和配对继续复用已有实现。无屏构建继续走原接口，LVGL 留在板端 UI 实现。

## 接口与分工

- **圆屏 Agent**负责 `main/ui/round_amoled/` 的布局和状态，检查既有配网、认领遮罩和定时更新。先用本地示例文本验证版式，再接入真实字幕。主界面清理可从当前主干开始。
- **固件字幕 Agent**负责 `main/protocol/voice_client.*` 与 `main/app/` 的事件接入，和圆屏 Agent 约定跨线程更新的单一接口。沿本轮 `turn_id` 显示转写和回复，实际开始播放时显示回复，取消、断线、解绑和播完时清屏。无字幕的服务端继续沿用原交互。
- **协调者**核对 [语音固件 PR #10](https://github.com/yuyuyulin/AgentSphere-esp32/pull/10) 与 [服务端字幕合同 #57](https://github.com/yuyuyulin/AgentSphere/issues/57) 的状态，再关联端云样例。语音固件尚为草稿，字幕消费实现以语音基线和联合合同为前置。用户手动指定实现人员。

## 验收

1. 在微雪 1.75C 上观察待机、聆听、思考和播报，主画面可读且无常驻调试信息。确认眨眼、招手、熄屏和亮屏保持正常。
2. 复测首次配网、配对、重启恢复绑定、断网提示和重连。确认需要操作时能看到准确的下一步，回待机后提示收起。
3. 用真实问答检查短句完整显示、中英文及超长文本的换行、字幕与声音对应、跨轮和取消不残留。校对设备与服务端播放回执。
4. 记录 ESP-IDF v6.1 的 1.75C 与无屏构建、固件大小和分区余量。真机照片和音频证据在用户确认后独立记录。
